# W3.1 教学密度状态机 · 公开合成测试

本文件只定义零敏感数据的通用规则，给公共 Actions 回归使用。真实稿件、章节候选、读者身份、词义和模型输出**仅存私人本机**。

- 尚未生成 → 密度失败 → 密度通过但待教学终审 → 教学终审通过。
- P1/P2 任一密度问题：阻断向后自动续写；但保留已生成章，不从头重写。
- 章节身份或词卡 ID 不一致、原始 SHA 变化、正在运行模型任务、人工未确认：拒绝修订候选安装。
- 密度通过本身**绝不构成出版上架许可**。
- 私人 W3.1 补丁：单独 CSS（兼容严格 CSP）、章节密度明细/分类、候选 JSON 只读预检、确认后备份安装、可选显式一次 CLI 生成修订候选、不自动安装/上架。
- 公共合同只测试状态逻辑，不包含或间接调用任何 Codex、Claude、Gemini 实际 CLI、Cloudflare 或 D1。
