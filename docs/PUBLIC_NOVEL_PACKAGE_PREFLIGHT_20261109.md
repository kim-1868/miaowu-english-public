# PUBLIC · 小说 JSON 上传前预检（2026-11-09）

适用：运营人员准备导入新书或更新已下架小说时，提前审查 JSON 的**结构、目标词引用、字段完整性与旧版本身份**。本工具只读取本地文件、不联网、不上传用户书稿、不创建任何生产部署配置。

## 运行

```bash
node scripts/inspect-novel-package.mjs "/本机路径/新版小说.json"
```

如果已有**授权导出的原版 JSON**，可再运行：

```bash
node scripts/inspect-novel-package.mjs "/本机路径/新版小说.json" "/本机路径/原版小说.json"
```

未提供原版时，只检查文件自身，**不会**声称与生产数据兼容。原版仅用于本机对比，不复制到 GitHub 或任何 CI。公开 Actions 的测试文件全部是虚构内容。

## 检查项

- JSON version=1、书籍 ID/等级、章节/卡片数量、段落/词汇引用、旧章节的 ID 是否保留；
- 英国/美国音标、释义、英中例句是否填写，文本有没有整段缺学习词；
- 同一词义是否意外生成不同 ID，历史词卡字段变动须另行人工审核；
- 2MB 原始文件、1.5MB 运行时 JSON 上限、修订入口 500 词卡的限制；
- 输出机器可读 JSON：`ok`、`errors`、`warnings`、`stats`。零 errors 不等于教学终审、版权审核或正式可售。

## 仍需私人正式站

真实旧书存在会导致 `POST /api/ops/import` 返回 `BOOK_ALREADY_EXISTS_USE_VERSIONED_REVISION (409)`；这需要生产运营台使用私人 PR #203 的修订入口。生产版本化备份 `ops_live_book_versions`、原书实际历史快照和 Cloudflare 部署属于私人生产环境，不能迁至公共仓库。公开测试通过不会消除生产登录/额度/D1 阻碍。

**注意：不要删除/改掉旧书 ID 来绕过 409，也不要上传真实售卖小说到公共仓库。**
