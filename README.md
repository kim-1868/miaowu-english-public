# 妙屋英语 WordLetter · 公共开发仓库

**仓库状态：公共开发入口已建立，网站代码尚未迁移。** 这个仓库不代表线上正式站，也不提供真实账号、兑换、阅读或运营后台服务。

妙屋英语采用 **公共开发仓库 + 私人核心仓库** 的长期架构。本仓库优先承接可公开的 UI、响应式布局、通用组件、非敏感的功能逻辑及离线自动测试，利用公共仓库的标准 GitHub 托管运行器完成日常 CI。

## 可放在这里的内容

- 网站的公共展示页面、布局、样式、图标与不涉密的前端交互；
- 通用的 UI 组件、无敏感业务依赖的模块、公开接口契约；
- **完全合成**的演示数据及测试夹具、离线单元测试；
- 不含凭据、不访问真实数据库、不触发正式部署的构建与检查工作流。

## 必须保留在私人核心仓库的内容

- 小说原稿、发布前内容包、受限词库源数据及内部审核资料；
- 用户、订单、激活码、学习记录等真实数据及数据库备份；
- 敏感鉴权/付费业务实现、运营管理操作、生产迁移脚本及部署配置；
- Cloudflare / GitHub 密钥、Token、真实环境变量或生产账号标识；
- 私人仓库的 Git 历史（包括曾经提交、后来删除的文件）。

**严禁 fork、mirror、复制 Git 历史或全量复制私人仓库。** 只允许从已审核的文件白名单中迁移确实可公开的文件，形成公共仓库自己的干净提交历史。

## 开发与集成规则

1. 新需求先分类：可公开的 UI/通用模块在本仓库开发；涉及敏感业务或受限内容的模块留在私人仓库。
2. 公共 CI 默认只跑无需密钥的静态检查、构建和离线测试，不连接 D1，也不部署任何生产或测试 Worker。
3. 服务端权限校验、付费阅读、词卡身份及用户数据由私人环境最终验收。
4. 公共前端的接口只使用非敏感契约和模拟数据；整合到私人仓库后再做端到端验收。
5. 对于每个公开提交，检查文件内容、提交历史、构建产物、测试 fixture 和 Actions 日志。发现敏感信息时停止公开。
6. 保持现有生产 Pages / Workers / D1、已购权益、预览站网址和数据库原样，改动必须另行审核。
